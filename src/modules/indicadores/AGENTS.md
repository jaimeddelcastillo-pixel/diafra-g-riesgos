# Indicadores
- K2-a annual Excel templates use the active filters and protected OOXML cells; preview/apply are server RPCs, with set-based validation and calls to guardar_kpi_resultado for changed cells, max 5000 and atomic audited reason; semantic success/warning/destructive tokens render the stored semaphore independently of review state; why: one calculation/write path and unambiguous year cells.
- K2 KPI results live in kpi_resultados with server-computed valor/cumplimiento/semáforo (kpi_calcular), an immutable meta/tendencia/unidad snapshot, one active result per KPI+period, periods only via kpi_periodo/kpi_ultimo_cerrado (America/Mexico_City, open periods rejected) mirrored in src/modules/indicadores/lib/resultados.ts; writes only via guardar/revisar/anular/asignar_capturistas/registrar_kpi_evidencia/ligar_kpi_evidencia RPCs (GUC tracea.kpi_resultados_rpc); KPI records are read with explicit per-table columns (kpi_puesto has no nivel); SGC requires referencia_fuente, files are optional period evidence in kpi_evidencias linked via kpi_resultado_evidencia; why: auditable capture that never recalculates past periods nor bypasses human review.
- K3-a period summaries (trimestre/semestre/año) come only from kpi_resumen_periodo: access checked once via kpi_acceso, accumulated Σnum÷Σden through kpi_calcular with the last copied meta, «sin base» excluded, weighted indices only over KPI with data; the Tablero and its Excel only render that result; document charts use src/lib/documentos/graficas.ts; why: one auditable calculation, never averaged percentages.
- K3-b periodic reports live in kpi_reportes (IND-AAAA-NNN, estado borrador/emitido/anulado + etapa), insert-only kpi_reportes_historial and versioned kpi_reporte_config; writes only via their RPCs (GUC tracea.kpi_reportes_rpc); emission atomically freezes kpi_resumen_periodo, format/identity with its DOC folio and signers; authorizer = AC holder, accepted valid AC substitution with «autorizar», or (no active AC) admin-designated users, never the author or reviewers; issued Word renders only from the snapshot; why: reproducible, segregated approvals.
